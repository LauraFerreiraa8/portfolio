#### 1. 🔍 Desafios e Algoritmos de Busca: Linear vs. Binária (Java)
Este repositório reúne implementações e testes práticos de algoritmos de busca para análise Comparativa de Performance. [cite_start]Inclui um desafio prático operando num cenário massivo com um array de 1 milhão de elementos para demonstrar o impacto real do design de algoritmos na eficiência do sistema[cite: 1].
- [cite_start]**Tecnologias:** Java SE (Standard Edition), Arrays, `java.util.Scanner`, `java.util.Random`[cite: 1].
- **Destaques de Análise/Desenvolvimento:**
  - [cite_start]**Análise Comparativa:** Demonstração empírica da diferença entre o pior cenário da Busca Linear ($O(n)$) e a eficiência logarítmica da Busca Binária ($O(\log n)$), reduzindo uma pesquisa de milhares de passos para apenas 20 iterações em 1 milhão de registros[cite: 1].
  - [cite_start]**Busca Linear Interativa:** Implementação que simula de forma didática o "pensamento" da máquina ao inspecionar posições sequenciais num array aleatório[cite: 1].
  - [cite_start]**Busca Binária Estruturada:** Algoritmo baseado na estratégia de *Divisão e Conquista*, aplicando controle preciso sobre índices delimitadores (`inicio`, `meio` e `fim`) e exigindo estruturas de dados previamente ordenadas[cite: 1].
